# malilion · 2026 real-world demo

[Open the report](https://malilion.github.io/RecapLion/demo/malilion-2026/)

This is the Traditional Chinese RecapLion report for [malilion](https://github.com/malilion),
with 12 curated project stories, 15 built-in achievements and 3 evidence-based special achievements.
`index.html` is the self-contained report; `cards/` contains 18 animated achievement SVGs and
the summary card used on the landing page.

The snapshot ends at **2026-11-17 15:21 Asia/Taipei** (07:21 UTC). It is a saved example,
not an automatically refreshed report. It contains 1,796 GitHub calendar contributions,
1,634 commit contributions, 33 projects, 52 active days and an 11-day longest streak.

The report uses GitHub GraphQL calendar data. Project stories were written from the public
repositories' READMEs and this year's commit samples. All listed projects are public;
raw API responses and internal commit-message samples are not included here.

Statistical notes also appear at the bottom of the report:

- Calendar contributions follow GitHub's contribution rules and differ from commits found
  across every branch by the search API.
- Commit-hour statistics use 525 sampled commits in the Asia/Taipei timezone.
- Language weights combine each repository's language proportions with commit activity.
- Stars are a snapshot of current totals, not stars gained during the year.
- Releases include at most the latest five per repository, so the visible total is not
  necessarily the full annual total.
- Merged PRs use a search by merge date and differ in scope from calendar PR contributions.
- Special achievements are narrative awards based on project evidence, not GitHub badges.
