How it works

Data from GitHub. The story from your agent.

The scripts crunch the numbers; your AI agent reads what you actually built and writes the narrative.

📡

Collect your year

Contributions, commits, PRs, issues, repositories and languages from the GitHub API — with or without a token.

🧠

Your agent writes the story

It reads READMEs and commit history, then writes project highlights, a headline, and special achievements the numbers can't see.

✨

Animated page + cards

A single self-contained HTML page and animated SVG cards you can embed in your GitHub profile README.

🔢

Year in numbers

Contributions, streaks, busiest day and golden hour, with count-up animations.

🟩

Animated heatmap

Your contribution calendar waves in, plus monthly bars and a commit-hour clock.

📦

Project cards

Every project you pushed gets a category, a pitch and concrete highlights.

🃏

Install

Up and running in a minute

Pick whatever fits how you work.

Installs the skill for Claude Code (~/.claude/skills) and Codex / other Agent Skills clients (~/.agents/skills), auto-detected.

curl -fsSL https://raw.githubusercontent.com/malilion/RecapLion/main/install.sh | sh

Or install into any agent's skills folder:

git clone https://github.com/malilion/RecapLion.git && sh RecapLion/install.sh --dir ~/path/to/skills

Then ask your agent:

“Make my 2026 GitHub year in review. My username is octocat.”

Add the marketplace, then install the plugin:

/plugin marketplace add malilion/RecapLion
/plugin install recaplion@recaplion

Then ask your agent:

“Make my 2026 GitHub year in review. My username is octocat.”

One command gives you every stat, chart and built-in achievement. Only Python 3.9+ is needed.

git clone https://github.com/malilion/RecapLion.git
python3 RecapLion/skills/github-year-review/scripts/recap.py --user octocat --tz Asia/Taipei

It asks whether to cover public repositories only or include your private ones (or pass --scope public / --scope all). Add --lang zh for Traditional Chinese; run gh auth login first for complete data.

Keep the cards on your profile fresh: copy the workflow into your profile repository's .github/workflows/ folder.

curl -fsSL -o .github/workflows/recaplion.yml https://raw.githubusercontent.com/malilion/RecapLion/main/examples/github-action/recaplion.yml

Then embed the summary card in your README:

![Year in review](./recap/cards/summary.svg)
